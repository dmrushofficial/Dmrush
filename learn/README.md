# DMrush Learn

Frontend-only Phase 1 for `learn.dmrush.com` — DMrush Institute learning platform.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS v4
- DM Sans

## Scripts

```bash
npm run dev
npm run lint
npm run typecheck
npm run build
```

## Notes

- No backend, auth, database, or payments in this phase
- Student/teacher dashboards use mock data and are `noindex`
- Agency link: https://dmrush.com
